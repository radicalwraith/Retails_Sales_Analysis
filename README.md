# 🛒 Walmart Retail Sales & Holiday Impact Analysis

## 📅 Duration
**October 2024 – November 2024**

## 📌 Project Overview
This project focuses on building an end-to-end data pipeline to analyze Walmart's e-commerce sales and understand the impact of public holidays on purchasing trends. By integrating sales and holiday data, the pipeline delivers actionable insights for optimizing inventory planning, promotional strategies, and supply chain decisions.

## 🧰 Tools & Technologies
- **Python**
- **Pandas**
- **NumPy**
- **CSV Processing**
- **ETL (Extract, Transform, Load)**

## ⚙️ Key Features
- Merged Walmart grocery sales data with U.S. public holiday information
- Cleaned and transformed raw datasets, handling missing values and data types
- Aggregated weekly sales into monthly averages, with contextual holiday data
- Exported ready-to-use datasets for further analysis and visualization

## 📁 Output Files
| File Name         | Description                                      |
|------------------|--------------------------------------------------|
| `clean_data.csv` | Cleaned dataset with merged sales and holidays   |
| `agg_data.csv`   | Aggregated monthly sales with holiday indicators |
| `pipeline_script.py` | Complete ETL and aggregation script         |

## 📊 Outcome
The pipeline helps identify how holidays affect consumer spending patterns at Walmart. These insights can support decisions related to:
- Promotional timing
- Inventory stocking
- Logistics planning

## 🚀 Getting Started
1. Clone this repository
2. Run `pipeline_script.py` to generate clean and aggregated datasets
3. Use the `.csv` files for your own analysis or visualization tools (e.g., Tableau, Power BI)
